# Infinite Loop - While Loop Experiment

A simple Python experiment to understand how `while True` works.

## How It Works

- x starts from 1
- while True always stays True, so the loop never ends
- In every loop, x increases by 1

## Note

This loop does not stop by itself. Press Stop or Ctrl + C to exit.

## What I Learned

- How while loop works
- What an infinite loop is
- Why a loop condition is important
